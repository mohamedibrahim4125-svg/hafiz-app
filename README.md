# تطبيق «حافظ» للموبايل (أندرويد)

## أسهل طريقة: GitHub يبني التطبيق مجانًا (من غير ما تسطّب حاجة)

1. اعمل حساب على **github.com** لو مش عندك.
2. اضغط **+** فوق ← **New repository** ← اكتب اسم مثلًا `hafiz` ← **Create repository**.
3. في صفحة المشروع اضغط **uploading an existing file**، واسحب كل اللي جوه فولدر `hafiz-app`
   (الفولدرات `www` و`scripts` و`resources` والملفات `package.json` و`package-lock.json` و`capacitor.config.json`)
   ← **Commit changes**.
4. اضغط تبويب **Actions** ← **set up a workflow yourself** ←
   امسح اللي مكتوب، والصق محتوى ملف `build-apk.yml` كله ← **Commit changes**.
5. استنى من ٥ لـ ١٠ دقايق لحد ما العلامة تبقى ✅ خضرا في تبويب **Actions**.
6. من الموبايل افتح صفحة المشروع ← **Releases** (على اليمين) ← نزّل **hafiz.apk**.
7. افتح الملف على الموبايل ← لو طلب «السماح بالتثبيت من مصادر غير معروفة» وافق ← **تثبيت**.

> أي تعديل ترفعه بعد كده، GitHub بيبني نسخة جديدة لوحده، وتتسطّب فوق القديمة من غير ما تقدّمك يتمسح.

## أول مرة تفتح التطبيق
- أول ما تستخدم التسميع بالصوت هيطلب إذن **المايك**، اضغط **سماح**.
- التسميع بالصوت بيستخدم خدمة التعرّف على الصوت من Google اللي على الموبايل، ومحتاج إنترنت.
  لو مابيشتغلش: اتأكد إن تطبيق **Google** متسطّب ومتحدّث.
- صوت المشايخ محتاج إنترنت، أما نص المصحف والتمارين فبيشتغلوا من غير نت.

## نقل تقدّمك من الكمبيوتر للموبايل
من الكمبيوتر: الرئيسية ← **نسخة احتياطية** ← ابعت الملف لنفسك (واتساب أو إيميل).
من الموبايل: الرئيسية ← **استرجاع** ← اختار الملف.

## طريقة تانية: Android Studio على الماك
1. سطّب **Node.js** و**Android Studio**.
2. في الترمنال جوه الفولدر: `npm install` ثم `npm run android:setup`
3. افتح فولدر `android` في Android Studio ← **Build ← Build APK(s)**.
